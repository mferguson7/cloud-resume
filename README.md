# Cloud Resume Challenge

A cloud-hosted resume website built as part of the Cloud Resume Challenge.

## 🌐 Live Website

[View my cloud resume](https://your-cloudfront-domain-here)

## 📌 Project Overview

This project demonstrates how I built and deployed a resume website using AWS cloud services, GitHub, and automated deployment.

The website includes a visitor counter that records and displays the number of visitors.

## ☁️ AWS Services Used

- **Amazon S3** — Hosts the static website files
- **Amazon CloudFront** — Delivers the website globally and provides HTTPS
- **AWS Lambda** — Handles the visitor counter logic
- **Amazon DynamoDB** — Stores the visitor count
- **Amazon API Gateway** — Provides the API endpoint used by the website
- **GitHub Actions** — Automates deployment of website changes
